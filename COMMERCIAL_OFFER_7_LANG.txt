КОММЕРЧЕСКОЕ ПРЕДЛОЖЕНИЕ: ХОККЕЙ (HOCKEY-POINT)
=================================================

Дата: 17 июля 2026
От: pop31-ai
Тема: Аркадная хоккейная игра в браузере — AI + игрок

───── ОПИСАНИЕ ПРОДУКТА ─────

Хоккей (Hockey-Point) — это браузерная аркадная игра с видом сверху, в которой
искусственный интеллект управляет обеими командами (5 полевых + вратарь), а
пользователь берёт на себя управление одним полевым игроком, влияя на исход матча.

КЛЮЧЕВЫЕ ХАРАКТЕРИСТИКИ:

  • AI управляет всеми игроками — игра идёт сама, игрок добавляет решающий фактор
  • Анимированные сцены: вбрасывание судьёй, драки, заморозка шайбы вратарём,
    свисток с кольцами, смена составов через скамейку запасных
  • Полноценный матч: 3 периода × 60 секунд, смена сторон
  • Трибуны с анимированной толпой
  • Звуковые эффекты через Web Audio API (без внешних файлов)
  • 1 HTML-файл — открыл и играешь, не требуется интернет

ТЕХНОЛОГИИ:
  Чистый JavaScript (ES6+) | Canvas 2D | Web Audio API
  Размер: ~50 КБ (сжатый ~18 КБ)
  Платформа: любой современный браузер (Chrome, Firefox, Edge, Safari)

МОНЕТИЗАЦИЯ:

  1. Лицензирование (игровые порталы, браузерные платформы)
  2. Private label / white label для турниров и мероприятий
  3. Расширенная версия с дополнительными режимами (2 игрока, онлайн)
  4. Интеграция рекламы (in-game баннеры, видео перед матчем)

ЦЕЛЕВАЯ АУДИТОРИЯ:
  • Поклонники хоккея всех возрастов
  • Любители казуальных браузерных игр
  • Организаторы спортивных мероприятий (киоски, фан-зоны)
  • Корпоративные клиенты (тимбилдинг, мини-турниры)

СТАТУС: v2.1 — рабочий прототип, готовый к публичному запуску и масштабированию.

  Лицензия: индивидуально

TECHNOLOGY:
