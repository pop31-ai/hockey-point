❄️ Обзор игры

Хоккей — это аркадный симулятор хоккея с видом сверху, где искусственный интеллект управляет обеими командами, а игрок берёт на себя роль центрфорварда и может переключаться между полевыми игроками своей команды.

Матч состоит из 3 периодов по 60 секунд. Команды меняются воротами после каждого периода. Побеждает тот, кто забросил больше шайб.

🔊 Звуковая система

Все звуки синтезируются через Web Audio API — никаких аудиофайлов не требуется. Нажми M в игре чтобы включить/выключить.

Уровень сложности AI

AI играет на комфортном уровне — не идеально (иногда теряет шайбу, ошибается в пасе), но достаточно competently чтобы игра была интересной. Шанс на драку после хита — ~3% у AI, ~5% у игрока. Шанс на заморозку шайбы вратарём — при сильном броске (скорость шайбы > 3).
