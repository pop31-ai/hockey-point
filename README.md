## ✨ Особенности

| Возможность | Описание |
|-------------|----------|
| **🤖 AI за обе стороны** | 5 полевых + вратарь в каждой команде. AI пасует, бросает, применяет силовые, меняет позиции |
| **👤 Ты на льду** | Управляешь игроком своей команды (★). WASD, бросок, пас, силовой приём. Без тебя игра идёт, но с тобой — победа! |
| **🔊 Звуки** | Свисток, удар шайбы, гудок при голе, крик трибун, хит — всё через Web Audio API |
| **👥 Скамейка запасных** | 3 запасных на лавке, смена составов по кнопке или автоматически |
| **⚔ Драки** | После силовых приёмов игроки могут подраться — кружение, удары, разнимание |
| **🧊 Заморозка шайбы** | Вратарь ловит и накрывает шайбу — подъезжает судья, вбрасывание |
| **🔔 Свисток** | Анимированные кольца звука от судьи при вбрасывании |
| **🏟️ Трибуны** | 4 ряда болельщиков сверху и снизу, прыгают после голов |
| **📊 Табло** | Светящийся счёт, время, периоды, броски, логотипы команд |
| **🔄 3 периода** | После каждого — смена ворот. Полноценный матч |
| **🎮 Tab — смена игрока** | Переключайся между полевыми своей команды |

## 🧊 Анимированные сцены

### 🔔 Свисток судьи
```
   (())
     ↑
   ═╪═  ← кольца звука
    ╪
   / \   ← свисток
```

Во время вбрасывания от судьи расходятся белые круги — имитация звуковой волны.

### 🧤 Заморозка шайбы вратарём

При сильном бросе вратарь накрывает шайбу:
- Шайба исчезает под вратарём (значок ✕)
- Судья подъезжает к вратарю
- ⭐ Анимированные искры вокруг вратаря
- → Свисток → Вбрасывание в зоне

### ⚔ Драка (потасовка)

После силового приёма есть шанс, что игроки начнут выяснять отношения:

1. **Кружение** — игроки наворачивают круги друг вокруг друга
2. **Удары** — поочерёдно наносят удары (с анимацией и звуком)
3. **Разнимание** — подъезжают остальные игроки, драка прекращается
4. → Свисток → Вбрасывание

### 🪑 Скамейка запасных

```
┌──────────────────┐
│ ════════════════ │  ← крыша скамейки
│ ⑩   ⑤   ②②    │  ← сидящие запасные
│ ─────────────── │  ← сиденья
│  СИНИЕ          │  ← название команды
└──────────────────┘
```

- На скамейке 3 запасных (с номерами)
- Слегка покачиваются в ожидании
- При смене состава уставшие игроки уезжают, запасные выезжают на лёд

### 🔄 Смена составов

У каждого игрока есть **энергия** (полоска над синими игроками):
- 🟢 100–50% — зелёный, полная готовность
- 🟡 50–25% — жёлтый, устал
- 🔴 < 25% — красный, еле двигается

**Ручная смена:** нажми `L`
**Автоматическая:** при `энергия < 60` во время смены

## 🛠 Технологии

- Чистый **JavaScript (ES6+)** — никаких библиотек
- **Canvas 2D** — вся графика и анимации
- **Web Audio API** — звуковые эффекты (синтезированные, без внешних файлов)
- Один **HTML-файл** — открыл и играешь

## 🚀 Запуск

Достаточно скачать `hockey.html` и открыть в любом современном браузере:

```
git clone https://github.com/pop31-ai/hockey-point.git
cd hockey-point
start hockey.html     # Windows
open hockey.html      # macOS
xdg-open hockey.html  # Linux
```

Или просто перетащить файл в окно браузера.
